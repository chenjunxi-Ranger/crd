## 4. 结构性判断

1. **C3 放宽是有效的**：与冻结 CLIP 的最好结果（COCO 0.9556 / Flickr 0.9691 / MM-IMDb 0.8415 /
   FOIL 0.8835）相比，适配后 COCO +1.2、MM-IMDb +4.0，FOIL 的余弦本身也从 0.8835 升到 0.926。
2. **FOIL 与行级的 λ 仍不同向**：FOIL 在 λ≈0.2 最好（0.922），行级在 λ≈0.8 最好。
   冻结 λ=0.8 时 FOIL 掉到 0.884。这是同一冲突在适配后的延续。
3. **MM-IMDb 只在 λ≥0.8 时才过线**，且余量 +0.0011——统计上等于贴线。
