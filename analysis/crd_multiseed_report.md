## 3. 为什么种子波动这么小

CRD 只拟合一个 65 维输出的加性头（`a(u)+b(v)+b0`），在 32,000 个训练行上做 Huber 回归。
模型容量小、目标平滑（只在预测 cycle 均值），所以对初始化不敏感。
这不是"结果好"，而是**这个机制本身方差低**——对论文是优点（可复现）。

## 4. 仍然存在的限制

| 限制 | 处理 |
|---|---|
| 仅 VG Attribute 做了多种子 | Relation / Quantity 仍是单种子，需在论文中标注 |
| VG Relation 的 val R² = −0.745 | 结果标为探索性；**不按 test 重选 λ** |
| 仅 B/16 | 不宣称 backbone-agnostic |
| λ 只来自 val，且 VG150 的 val 非随机子集 | 在局限性中披露；补一个"随机切分 val"的稳健性检查 |

## 5. 冻结的方法定义

```
训练阶段（每个 cycle，4 条样本）
  m_c = mean(s_AA, s_AB, s_BA, s_BB)            # 冻结 CLIP 的 cycle 基线
  m̂(I,T) = a_φ(u) + b_ψ(v) + b0                 # 加性偏置预测器
  L = Huber(m̂(I,T), m_c)                        # 仅此一个损失

推理阶段（单个图文对）
  s_CRD(I,T) = s_CLIP(I,T) − λ·m̂(I,T)
  λ 由验证集选定；不需要 partner、参考库或额外前向
```

**理论性质**：`Δ' = Δ`（加性项在互惠 cycle 的四项差分中抵消），
数值验证最大误差 8.94e−08 ~ 1.19e−07。
