# 决策记录：CRD 监督目标由 cycle mean 改为 row-level

> 2026-11-09。按预注册规则：**三项检查全部通过后才可采用 B**。

## 1. 三项检查

**C1 · 其他语义维度（CLIP B/16，各 3 种子，λ 由 val 选）**

| 维度 | cycle mean | row-level | row − cycle |
|---|---:|---:|---:|
| VG Attribute | 0.7096 ± 0.0003 | **0.7149 ± 0.0002** | **+0.53** |
| VG Relation | 0.5556 ± 0.0013 | **0.5586 ± 0.0012** | **+0.30** |
| COCO Quantity | 0.8844 ± 0.0009 | **0.8903 ± 0.0015** | **+0.59** |

**C2 · 其他视觉语言基座（SigLIP2 B/16，VG Attribute，3 种子）**

| 目标 | AUROC | Δ vs SigLIP2 原生 0.7026 |
|---|---:|---:|
| cycle mean | 0.7431 ± 0.0004 | +4.05 |
| **row-level** | **0.7509 ± 0.0003** | **+4.83** |

row − cycle = **+0.78 pp**，比 CLIP 上的 +0.53 更大。

**C3 · 配对统计（10,000 次 cycle 聚类 bootstrap）**

| 项 | 值 |
|---|---|
| AUC（三种子平均分数）cycle / row | 0.7104 / **0.7156** |
| Δ | **+0.52 pp** |
| 95% CI | **[0.48, 0.57]** |
| P(Δ > 0) | **1.00** |
| 逐种子 Δ | +0.547 / +0.520 / +0.522 |

**三项检查结论：row-level 在三个维度、两个基座上一致领先，配对 CI 不含 0。→ 采用 B。**

## 2. 新的官方配置

```
训练目标  : m(I,T) = s(I,T)            # 该图文对自身的 CLIP 分数（不再用 cycle 均值）
模型      : m̂(u,v) = a(u) + b(v) + b0  # 不变
损失      : Huber( m̂ , m )              # 不变
推理      : s_CRD = s − λ·m̂             # λ 由 val 选（Attribute 上为 0.7）
```

**注意 λ 变了**：Attribute 从 1.0 降到 0.7，Quantity 从 1.1 降到约 0.9–1.0。

## 4. 对方法叙述的影响（必须改写）

原叙述：*用 reciprocal-cycle 监督学习可加偏置*。

新叙述：*CRD 学习图像–文本相似度表中的可加主效应 `a(u)+b(v)`，推理时扣除；
reciprocal cycle 是评测基准的结构，不是训练所必需的目标。*

对应解释：这等价于**对相似度矩阵做双中心化**，只是主效应被参数化为 `u`、`v` 的函数，
因此可以外推到训练时未出现过的图文对。cycle mean 只是该目标的一个免标注近似，
而且被证明是更粗糙的近似（A3）。

**A4 的安慰剂仍是有效证据**：把 cycle 打乱后 R² 转负、增益消失——这说明增益来自
"目标与真实分数对应"，而不是头部容量。
