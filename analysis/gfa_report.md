## 3. 失败的直接证据

训练损失从 0.83 只降到 **0.7368**，而 50/50 标签下的随机基线是 **ln2 = 0.6931**。
也就是说 400 步后模型**几乎没学到配对判别**——它连"把 clean 排到 noisy 前面"都没做到。

对比：C2S（M2/M3）在同一数据上是 600 步 × 128 行 ≈ 76,800 样本；
GFA v1 只用了 400 × 16 = 6,400 样本，**少一个数量级**。
所以严格说：这轮否定的是"**该预算下的 GFA 实现**"，不是"事实定位没用"。

## 4. 但有一个结构性疑点，比预算更值得注意

GFA 的分数是 `s = α·cos + (1−α)(2σ(q)−1)`，α=0.5。
若 `q` 学不出来，s ≈ 0.5·cos + 0.5·noise，**分数会被随机项稀释**——
这正好解释了为什么 GFA（0.6053）显著低于纯余弦（0.6806），而不是持平。

也就是说：只要 q 不显著优于随机，混合就已经是负收益。
这个风险在设计里就存在，不是实现 bug。

## 5. 决定

- CSLS 基线：**冻结**，λ 由 val 选定，作为正式基线发布。
- GFA：**关闭**（按预注册规则）。
- 若要再试，唯一有依据的改动是"先证明 q 单独可用（q 的 AUROC > 余弦），再谈融合"，
  而不是继续调 λ_g / α。
