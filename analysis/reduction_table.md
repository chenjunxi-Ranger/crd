# 归约检验表（Stage 3）

> 判据（CONSTRAINTS C7）：若候选分数可写成已知算子的单调变换，则淘汰。
> "可归约"指存在单调映射 $g$ 使 $s = g(s_{\text{known}})$，即排序完全一致。

| 已知算子 | 形式 | 与本公式的关系 | 判定 |
|---|---|---|---|
| CLIPScore | $2.5\max(\cos,0)$ | 本公式的 $-\cos$ 项是其单调变换 | 该项**不声称创新**，仅作基线 |
| CSLS | $2\cos - r_x - r_c$ | 本公式不含任何库统计，$r_x,r_c$ 不出现 | 不可归约 |
| CMC 边际 | $-\frac12(m_{img}+m_{txt})$ | 本公式无 top-1 竞争者 | 不可归约 |
| LEMoN | $d_1+\beta s_n+\gamma s_m$ | 无邻居项、无 $\beta/\gamma$ | 不可归约 |
| Deep k-NN | $-$同簇比例 | 无聚类 | 不可归约 |
| CLIP4DM | 词级梯度归因聚合 | 本公式用前向 token×patch 覆盖率的**均值**，无梯度、无 max-over-words | 不可归约（但同属"局部对齐"家族，需在正文说明差异） |
| 语料先验（VisualGPTScore 等） | $\log p(c)$ 加权 | 见证项已冻结为 0 | 不进入公式 |
| 池化竞争（SCOPE/SPARC） | 集合内 softmax 竞争 | 无参考池、无门控 | 不可归约 |

## 结论

1. 公式的**唯一非平凡项**是覆盖率 $\mathrm{cov}$，它与上表所有算子都不构成单调等价；
2. 但 Gate 已证明该项的判别力不足（COCO 单特征 0.63，FOIL 0.70），加入后 COCO 从 0.9295 降到 0.9242；
3. 因此本公式**合规但不达标**：它通过 C7，却在 C5 上失败。
