# RAT 准入审计报告

> 2026-11-04。实现：`scripts/rat_gate.py`；产物：`results/gate/rat_{coco,flickr,mmimdb}.json`。
> 全部来自冻结 CLIP 的一次 `output_attentions=True` 前向；无参数更新。

## 1. 三个模型

| 模型 | 输入 |
|---|---|
| M0 | `[s, h]`（余弦 + 库侧 CSLS 证据） |
| M1 | `[s, h, S_IT]`（跨模态相似度结构：每 token 的 max/mean over patches + std） |
| M2 | `[s, h, S_IT, A_I, A_T]`（再加图像 patch 自注意力、文本 token 自注意力） |

读出：5 折 CV，逻辑回归；矩阵类特征（A_I 2401 维、A_T 144 维）在**每折内**做 PCA-16。

## 2. 结果

| bench | n | M0 | M1 | M2 | **Δ(M2−M1)** | 95% CI |
|---|---:|---:|---:|---:|---:|---|
| COCO | 800 | 0.9599 | 0.9589 | 0.9519 | **−0.0070** | [−0.0111, −0.0017] |
| Flickr | 800 | 0.9683 | 0.9655 | 0.9594 | **−0.0060** | [−0.0159, +0.0010] |
| MM-IMDb | 800 | 0.8453 | 0.8348 | 0.8244 | **−0.0104** | [−0.0163, −0.0045] |

- **三列 Δ 全为负**，其中 COCO 与 MM-IMDb 的置信区间不含 0；
- **M1 也低于 M0**（−0.001 / −0.003 / −0.011）：连"跨模态相似度结构"本身在控制 `(s,h)` 后都没有增量。

## 3. 判定

按设的条件（"若 M2 与 M1 几乎一样，就不训练 RAT"），实际结果比这更差：**M2 显著低于 M1**。

**结论：不训练 RAT。**

## 4. 可信度边界

- 读出是线性 + PCA-16，容量有限；一个关系消息传递网络理论上可能提取更多结构。
  但"加入更多信息后**稳定变差**"这一现象，更可能说明这些矩阵相对标签主要是噪声——
  因为 PCA 投影在同一折内拟合，不存在泄漏。
- 只测了最后一层注意力（mean over heads）；多层平均未测。
- 未测 FOIL 的组级表现（行级已三列一致为负，按门槛不再继续）。

## 5. 与 DCSM 的关系

M1 相当于 DCSM 式跨模态相似度矩阵的简化读出，它在三列上都**没有**超过 `(s,h)`。
这说明该文报告的增益很可能来自 CNN 的结构先验 + 端到端训练，而不是相似度矩阵里
存在 `(s,h)` 之外的、可被线性读出捕获的信息。
