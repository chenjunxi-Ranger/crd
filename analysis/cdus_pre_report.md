# CDUS 零训练诊断报告

> 2026-11-04。实现：`scripts/cdus_pre.py`；产物：`results/gate/cdus_*.json`、`cdus_scores_*.npz`。
> 定义：$D_K=\frac1K\sum_{\ell}\cos(\Delta z^I_\ell,\Delta z^T_\ell)$，最后 K 层；
> 每层都用**同一读出**（post_layernorm/final_layer_norm + projection）。
> 全程无训练、无遮挡、无语料库。

**五条全部通过**，这是本仓库几轮候选里第一次出现"机制对照成立"的结果：
把文本第 $\ell$ 层的更新与图像第 $L-1-\ell$ 层的更新配对后，判别力从 0.62–0.70 掉到 0.53–0.56，
说明"同深度同步"不是任意两个向量的偶然余弦。

- COCO / Flickr 的最优点在 λ=0，任何正 λ 都掉点；
- MM-IMDb 偏好大 λ（0.5 时 +0.95），FOIL 偏好 0.05–0.2（+0.4）；
- 折中 λ=0.05 时：COCO −0.0001、Flickr −0.0001、MM-IMDb +0.18、FOIL +0.40。

## 4. 判定

**机制成立，但效应量不足。**

- 准入五条全过，说明"跨深度更新同步"确实携带与最终余弦不同的信息（尤其条件 MCA 0.55–0.62 > 0.5，而 VES 在 COCO 是 0.442）；
- 但 D 单独只有 0.57–0.70，融合后最多 +0.4 点，而四列分别还差 3.0 / 0.2 / 5.5 / 2.8 点；
- 统一 λ 让 COCO/Flickr 微降，MM-IMDb 与 FOIL 微升——没有一列因此接近门槛。

按你设的规则："统一 λ 仍然让某个数据集掉点，就结束"——λ=0.05 时 COCO/Flickr 各掉 0.0001，
属于噪声级，但也没有实质增益。

## 5. 结论与下一步

CDUS 是至今唯一通过机制对照的候选，但它的信息量比 VES 还弱（VES 在 FOIL 能到 +3.2）。
若要继续，唯一有意义的方向不是调 λ，而是**增强 D 的信噪比**：
例如用多层窗口的重叠平均、或用同一层的多个 token 对齐——但这会回到"局部对齐"家族，
与 CDUS 的"深度同步"卖点偏离。

我的建议：**归档 CDUS 为"机制成立、效应不足"**，不进入五阶段。
