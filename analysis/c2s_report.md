# C2S（Cycle-to-Single）第一轮：M2 vs M3

> 2026-11-07。冻结 CLIP ViT-B/32，只训练轻量交互头（u, v, u⊙v → MLP → 标量）。
> 训练：每 facet 1,500 cycles（Action 只有 423 个可用），共 6,423 cycles / 25,692 行。
> 目标：`L = BCE + λ·softplus(−Δ_cycle)`，λ=1，600 步。

## 2. 判定：不通过

预注册标准要求 **AUROC 提升 且 2AFC 不明显下降**。

| 条件 | 结果 |
|---|---|
| Attribute AUROC > 0.6786 | ✅ 0.6925（+1.39 pp） |
| Relation AUROC > 0.5439 | ✅ 0.5509（+0.70 pp） |
| Action AUROC > 0.5885 | ✅ 0.6052（+1.67 pp） |
| **2AFC 不明显牺牲** | ❌ Attribute −2.69、Relation −2.51、Quantity −2.63 |

**"AUROC 升、2AFC 降"正是你预先定义为失败的那种情形。**

## 3. Cycle loss 到底贡献了什么

M3 − M2（同为冻结特征，唯一差别是 cycle loss）：

| 维度 | ΔAUROC | Δ2AFC |
|---|---:|---:|
| COCO Entity | +0.06 | 0 |
| COCO Quantity | **+1.49** | **+1.76** |
| VG Action | +0.72 | −0.55 |
| VG Attribute | +0.17 | −1.35 |
| VG Relation | −0.34 | −1.71 |

只有 COCO Quantity 上 cycle loss 是"双赢"；VG 三维是"AUROC 微升、2AFC 下降"。
说明 **cycle 监督在全局特征上无法同时维持相对判别**——这与 R200 观察到的解耦是同一现象。

## 4. 与冻结 CLIP 相比的真实水平

M3 在 VG 上只比冻结高 **0.7–1.7 pp**，而 2AFC 缺口仍为：

| 维度 | M3 2AFC | M3 AUROC | 剩余缺口 |
|---|---:|---:|---:|
| Attribute | 0.806 | 0.693 | **11.3 pp** |
| Action | 0.757 | 0.605 | **15.2 pp** |
| Relation | 0.620 | 0.551 | **6.9 pp** |

缺口从 16.0 缩到 11.3（Attribute），但仍远未闭合。

## 5. 未使用的组件

当前实现只用了**全局向量**，公式里的 `g_ω(I,T)`（patch × token 局部交互）
**完全没有实现**。这既是本轮的局限，也是唯一还没被检验的部分。

## 6. 结论

- C2S 的"两目标协同"在**全局特征**上不成立：cycle loss 带来 AUROC 微升的代价是 2AFC 下降。
- 若还有下一轮，唯一有依据的方向是把 `g_ω` 换成真正的局部交互特征（patch/token 对应），
  而不是继续在全局特征上调整 λ 或步数。
