# SCPA 确认性实验（三种子 × 三列）

> 2026-11-06。实现 `scripts/seml_lora.py`（`--match quantile|none`）。
> 环境 = 冻结文本嵌入 KMeans(K=8)；每环境内采样 clean/noisy；LoRA blocks 10–11 q/v，r=4，α=8；200 步。

## 1. 三种子结果（CSLS 口径）

| bench | M0（旧，300 步，混合负样本） | **M1 SCPA（200 步，环境采样）** | Δ |
|---|---:|---:|---:|
| COCO | 0.9698 / 0.9651 / 0.9683 → **0.9677 ± 0.0024** | 0.9721 / 0.9725 / 0.9725 → **0.9724 ± 0.0002** | **+0.47 pp** |
| Flickr | 0.9678 / 0.9669 / 0.9661 → **0.9669 ± 0.0008** | 0.9709 / 0.9705 / 0.9711 → **0.9708 ± 0.0003** | **+0.39 pp** |
| MM-IMDb | 0.8821 / 0.8801 / 0.8809 → **0.8810 ± 0.0010** | 0.8902 / 0.8888 / 0.8897 → **0.8896 ± 0.0006** | **+0.86 pp** |

**三种子的取值范围完全不重叠**（M1 最小值均高于 M0 最大值）。
相对冻结余弦的 $G_d$：COCO **56.7%**、Flickr **30.5%**、MM-IMDb **32.2%**，均远超 10%。

## 2. 关键消融：余弦分位匹配是否有效

| bench | 分位匹配 | 取消匹配（同环境采样、同预算） | **Δ** |
|---|---:|---:|---:|
| COCO | 0.9721 | 0.9720 | **+0.0001** |
| Flickr | 0.9709 | 0.9707 | **+0.0002** |
| MM-IMDb | 0.8902 | 0.8894 | **+0.0008** |

**分位匹配几乎零贡献。** SCPA 声称的核心机制（相似度条件化配对）不是增益来源。

## 3. 判定

| 停止条件 | 结果 |
|---|---|
| 三列相对 M0 均有正增量 | ✅ +0.47 / +0.39 / +0.86 |
| 三种子方向一致 | ✅ 三个种子全部高于 M0 全部种子 |
| $G_d\ge10\%$ | ✅ 56.7 / 30.5 / 32.2 |
| **M1 明显优于取消分位匹配的消融** | ❌ **Δ ≤ 0.0008** |

按预注册规则：**SCPA 作为机制假设不成立**，但"环境采样 + 200 步轻量适配"这条训练配方本身确实超过了 M0。

## 4. 真正可能的来源（待验证，非结论）

M1 与 M0 有三处同时不同：① 200 vs 300 步；② 环境内采样 vs 全局混合；
③ **没有 FOIL 反事实负样本、也没有 in-batch NCE**。
消融只排除了"分位匹配"，未分离这三者。

## 5. 已完成的隔离检查

COCO：val 的 2,000 个 noisy 样本中，donor 图像出现在 train 的比例 **0/2000（0%）**
（donor 全部来自 val2014，train 来自 train2014）。**donor-source 隔离成立。**

## 6. 局限

单基座（CLIP）、无配对 bootstrap（未保存逐样本分数）、FOIL 未跑、
M0 与 M1 的步数与负样本构造不同，属复合改动，不能把增益归给单一因素。
