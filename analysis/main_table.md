## 四条结论

1. **Attribute**：CRD 全面领先（+3.16 ~ +3.85），且 2AFC 零损失。
2. **Action**：CRD **0.6145** 点估计高于 TRACED（0.6102），但 **Δ=+0.47 [−1.71, 2.72]，不显著**。
   能主张的是：**CRD 在 Action 上与 TRACED 相当，且 2AFC 零损失（TRACED 掉 3.25 pp）**，
   不能写"超越 TRACED"。
3. **Quantity / Entity**：**CSLS 仍更强**（0.8882 / 0.9996 vs 0.8837 / 0.9995），差异不显著但方向不利。
4. **GMM 不是更强的检测器**：AUROC 与余弦逐位相同，只是单调重标定 + 噪声率估计；
   且它的噪声率估计偏（Attribute 估 0.685，真实 0.5）。

## 4. Action 的内部验证协议

官方 val 仅 2 cycles，故从 train 划 20%：train 319 / val 80 cycles（train∩val 图像 = 0），
test 166 cycles 完全不动；μ/σ 只用 1,276 行训练数据；λ 由内部 val 选（0.6–0.7）。
