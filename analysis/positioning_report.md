# 重新定位：基座无关的检测机制

> 2026-11-05。约束见 `CONSTRAINTS.md §6`；接口实现 `src/scorer.py`（M1 的代码化）。

## 1. TRACED 的边界（必须避开的四件事）

| 维度 | TRACED | 我们不能重复的 |
|---|---|---|
| 输入 | 图像 + 可能错误的 caption | — |
| 操作 | **迭代编辑 caption** | 任何"改文本再比分数"的搜索 |
| 观察 | 编辑轨迹上的相关性变化 | 轨迹特征 + 分类器 |
| 训练 | 轨迹特征分类器 | "轨迹 + 轻量头"的组合 |

结论：**"改文本看分数变化"这一整类被占用**，包括我们此前的 C-VRR。

## 2. 标量接口下还剩什么

M1 只允许 $s_b(I,c)\in\mathbb R$。能把 $s_b$ 变成统计量的方式只有四种：

| # | 构造 | 代表 | 我们的结果 |
|---|---|---|---|
| ① | 分数本身 | Cosine | 基线 |
| ② | 分数在参考池中的位置 | CSLS / LEMoN | 已测，四列净正，无门控 |
| ③ | 分数对**文本扰动**的响应 | TRACED / C-VRR | 被占用 / 已否证 |
| ④ | 分数对**图像扰动**的响应 | VES / CRG | 已否证（MCA 0.44–0.49） |

①②③④ 全部被占用或已被我们否证。**所以"新机制"不可能来自换一种统计量，只能来自
同一个构造下不同的干预选择或不同的归一化方式。**

这是一个必须承认的结构性事实：M1 越严格，可创新的空间越小。

## 3. 唯一还没测过的格子

③④ 的失败都建立在**单侧、非配对**的扰动上。没测过的是：

> **配对、等幅的双侧扰动**——同一图文对，分别做一次良性的文本变更与一次良性的图像变更，
> 比较两侧的相对响应。

直觉：正确图文对的分数应当是**冗余**的（任一侧的良性扰动都不该大幅改变它）；
错误图文对的分数是**脆弱**的（本来就靠少数线索撑着，任一扰动都会击穿）。

形式化：记 $\Delta_T=s(I,c)-s(I,c')$，$\Delta_V=s(I,c)-s(I',c)$，其中 $c'$ 是同图的另一条人工描述，
$I'$ 是同一图像的中心裁剪（80%）。定义不对称度

$$
\mathrm{PPA}=\frac{\Delta_T-\Delta_V}{\max(|\Delta_T|,|\Delta_V|)+\epsilon}
$$

**可证伪预测**：控制 $s$ 与 $h$ 后，noisy 的 $|\mathrm{PPA}|$ 显著大于 clean。若条件 MCA ≤ 0.5，此格作废。

成本：每样本 3 次打分，满足 M5。

**C7 风险**：这与"增强一致性 / TTA 稳定性"相邻，很可能被审稿人视作已有思想。
必须在做之前确认：它不是 $\mathrm{Var}_\text{aug}[s]$ 的重新命名。区分点在于**跨模态不对称**，而不是单侧方差。

## 4. 如果这一格也失败

| 出口 | 代价 |
