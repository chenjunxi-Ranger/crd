# 三大实验类别 · 汇总（统一口径：`crd_backbone`，row 目标）

> 2026-11-09 更新。FGBench v1-strict；λ 只由 val 选；**全部基座使用同一套标准化管线**；
> 每种配置 3 个训练种子（`DATA_SEED=0` 固定数据与行序）。
> 旧 `crd_offset`（未标准化）结果保留，但**不进入本表**。

| 基座（评分机制） | Attribute | Relation | Quantity |

| CLIP B/16（余弦） | 0.6806 → **0.7187** (+3.81) | 0.5413 → **0.5530** (+1.17) | 0.8305 → **0.8837** (+5.32) |
| CLIP L/14（余弦） | 0.6779 → **0.7139** (+3.60) | 0.5420 → **0.5626** (+2.06) | 未跑 |
| SigLIP2 B/16（scale·cos+b） | 0.7026 → **0.7509** (+4.83) | 0.5578 → **0.5723** (+1.45) | 0.8947 → **0.9254** (+3.07) |
| BLIP-ITC（双塔余弦） | 0.7365 → **0.7803** (+4.38) | 0.5898 → **0.6163** (+2.65) | 0.9766 → **0.9812** (+0.46) |
| BLIP-ITM（融合 logit） | 0.8207 → **0.8478** (+2.71) | 0.6467 → **0.6585** (+1.18) | 0.9859 → **0.9880** (+0.21) |

2AFC（原生 = CRD，全部逐位相同）：CLIP 0.828163 / 0.650142 / 0.964912；
L/14 0.826763 / 0.652975；SigLIP2 0.862965 / 0.694051 / 0.982456；
ITC 0.893495 / 0.757790 / 0.991228；ITM 0.936839 / 0.766289 / 0.991228。

**三条结论**

1. 五种基座、四种评分机制，CRD 全部为正（+0.21 ~ +5.32 pp），**2AFC 无一例外逐位不变**。
2. **加大 CLIP 容量无效**：L/14 的 Attribute 0.6779 低于 B/16 的 0.6806，Relation 0.5420 ≈ 0.5413。
3. **Relation 上限由评分机制决定**：双塔全在 0.54–0.57，融合（ITM）到 0.6467。

## 实验三 · Ablation（CLIP B/16，VG Attribute，3 种子）

| 配置 | AUROC | SD | AUPRC | 2AFC | Δ vs 基座 |
|---|---:|---:|---:|---:|---:|
| Base | 0.6806 | — | 0.6680 | 0.828163 | — |
| Image-only `a(u)` | 0.6944 | 0.0001 | 0.6807 | 0.828163 | +1.38 |
| Text-only `b(v)` | 0.6956 | 0.0008 | 0.6904 | 0.828163 | +1.50 |
| **Additive（row，官方）** | **0.7187** | **0.0001** | **0.7177** | **0.828163** | **+3.81** |
| Cycle-level | 0.7125 | 0.0001 | 0.7077 | 0.828163 | +3.19 |
| Joint residual `+h(u,v)` | 0.7003 | 0.0014 | 0.6921 | 0.825572 | +1.97 |
| **Shuffled placebo** | **0.6806** | 0.0000 | 0.6680 | 0.828163 | **0.00** |

配对对照（cycle bootstrap，500 次 × 3 种子）：

| 对比 | Δ | 逐种子 |
|---|---:|---|
| Additive − Image-only | **+2.43 pp** | 2.42 / 2.45 / 2.43 |
| Additive − Text-only | **+2.31 pp** | 2.22 / 2.37 / 2.35 |
| Additive − Cycle-level | **+0.62 pp** | 0.62 / 0.64 / 0.60 |
| Additive − Shuffled | **+3.81 pp** | 3.82 / 3.82 / 3.80 |

**四条结论**

1. **超可加**：1.38 + 1.50 = 2.88 < 3.81（缺口 +0.93）→ 两侧互补，不可互替。
2. **row > cycle**（+0.62 pp）：cycle 均值把同 cycle 内本已存在的加性差异也平均掉了。
3. **安慰剂归零**：打乱 cycle 后 val 选到的 λ 就是 0（两/三个种子），R² 为负、AUROC 等于基座。
4. **联合残差失败**：R² 从 0.51 升到 0.63，但 AUROC 与 2AFC 同时下降 →
   超出可加成分的偏移与真实匹配信号不可分离，**可加性是必要条件**。

## 必须写进 limitations 的六条

1. **Quantity 上 CSLS 仍最强**（BLIP-ITC 基座 +0.24 ns；CLIP 基座 CRD 0.8837 < CSLS 0.8882）。
2. **Relation 绝对水平仍弱**（最好 0.6585），显著但区分力有限；CLIP 基座仅 0.5530。
3. **Action 的 CRD 使用内部验证协议**，与其它四个维度的官方 val 不同，表中须单独标注。
4. **Attr 的 F1 低于 cosine**（CLIP 基座 0.5015 vs 0.5260）——提高精度、牺牲召回。
5. **LEMoN / TRACED 为 `-style` 复现**；TRACED 每样本 ≈25× 前向。
6. **BLIP 为 COCO 检索微调权重**，其 Quantity 属域内结果，不能与零样本基座并列。
