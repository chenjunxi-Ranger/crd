## 4. CRD 在 SugarCrepe 上没有收益 —— 这是可预测的

**SugarCrepe 的二选一是在同一张图上比较两条文本。**

```
s'(I,T+) − s'(I,T−) = [s(I,T+) − s(I,T−)] − λ·[b(v+) − b(v−)]
```

图像侧 `a(u)` 在两侧**完全相同、严格抵消**。于是：
- CRD 的主要作用（去掉**每张图**的分数基线）在这里没有任何作用空间；
- 只剩文本侧 `b(v)`，而它是在 cycle 均值上拟合的，被图像效应主导 → 基本是噪声。

所以 SugarCrepe 上的 Δ ≈ 0 或略负，**与 FGBench 2AFC 严格不变是同一件事的两面**：
可加校正只在"跨图像比较"时有意义。

**应作为方法的适用范围边界写明，而不是当作外部失败。**

## 5. 这一轮能主张什么 / 不能主张什么

**能主张：**
1. BLIP-ITM 在 SugarCrepe 上 0.9270，且未见图上仍有 0.9197 —— 组合语义判别很强。
2. CRD 不损害外部任务（最大 −2.31，且是已见比例最高的配置）。

**不能主张：**
1. 不能说 CRD 提升了外部组合语义基准——它没有。
2. 不能把 BLIP 的数字和 CLIP/SigLIP2 当同条件比较：
   BLIP 是 COCO 检索微调权重，且 77% 的 SugarCrepe 图在其训练池内。
3. 不能说 SugarCrepe 成绩等同于"图文错标检测"——任务不同。
