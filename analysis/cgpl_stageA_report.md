# CGPL Stage A 审计报告

> 2026-11-04。实现：`scripts/cgpl_stageA.py`；产物：`results/gate/cgpl_{coco,flickr,mmimdb}.json`。
> 每列从官方 train 抽 300 clean + 300 noisy，构造 90,000 条 clean→noisy 比较边，
> 教师 $t_{ij}=\max(0,\tilde m^C_{ij},\tilde m^R_{ij})$，用加权 Laplacian 最小二乘求全局势 $a^*$。

## 1. 结果

| bench | ρ_global（最大边际教师） | ρ_global（Oracle 教师） | 循环残差 | 半图稳定性（Spearman） | **a\* 对 (s,h) 的多项式 R²** |
|---|---:|---:|---:|---:|---:|
| COCO | 0.9983 | 0.9795 | 0.0017 | 0.9999 | **0.9961** |
| Flickr | 0.9985 | 0.9845 | 0.0015 | 0.9999 | — |
| MM-IMDb | 0.9919 | 0.9420 | 0.0081 | 0.9997 | **0.9811** |

## 2. 形式上是通过的，但有两个致命的口径问题

**（a）ρ_global 高是构造性的。** 教师 $t_{ij}$ 由 $s$ 与 $z=s-0.5h$ 两个**全局标量函数**生成，
所以它几乎必然能被某个全局势函数解释。这个数字不能证明"pairwise Oracle 可分解"，
只证明"两个全局分数的最大值仍是一个全局量"。

**（b）即便换成 Oracle 教师，ρ 仍有 0.94–0.98**，原因是"两个专家都错"的样本是**节点集中**的
（少数 hopeless 的 noisy 样本对所有人都错），所以一个节点级势函数就能拟合这部分。

## 3. 决定性的数字：a\* 本身就是 (s,h) 的函数

$a^*$ 对 $[1,s,h,s^2,h^2,sh]$ 的多项式回归 $R^2$：

- COCO **0.9961**
- MM-IMDb **0.9811**

也就是说，势函数 98%–99.6% 可由 $(s,h)$ 解释。$F_\theta(\phi)$ 的输入
$\phi=[s,r_I,r_c,h,\dots]$ 里再多特征，也没有东西可学——**蒸馏只能复原 $(s,h)$ 的某个平滑函数**。

而"$(s,h)$ 的非线性融合"我们已经测过（GBM）：
**0.9429 / 0.9590 / 0.8479**，比线性融合（0.9607 / 0.9692 / 0.8732）还差。

## 4. 判定

| 判据 | 结果 |
|---|---|
| ρ_global 高 | ✅ 但是构造性的 |
| 半图稳定 | ✅ 0.9997–0.9999 |
| 势函数携带 (s,h) 之外的信息 | ❌ R² 0.981–0.996 |
| 预期蒸馏增益 | ≈ 0，且非线性融合已实测更差 |

**结论：CGPL 的训练阶段不会超过已有的线性融合上界（0.9607 / 0.9692 / 0.8732），
其中 MM-IMDb 仍差 0.68 pp。不建议进入 Stage B。**

## 5. 什么情况下 CGPL 才有意义

只有当势函数中存在 $(s,h)$ **无法解释**的成分（R² 明显 < 0.9），且该成分能被
$\phi$ 中的额外特征预测时，蒸馏才可能超过线性融合。当前 R² 是 0.98–0.996，没有这个空间。

要让 R² 降下来，需要教师信号本身包含 $(s,h)$ 之外的信息——而我们六轮审计已经证明，
在当前冻结 CLIP 上不存在这样的信号源。
